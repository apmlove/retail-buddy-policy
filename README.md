# retail-buddy-policy

The public Terms &amp; Privacy page for the **Retail Margin Buddy** app, served by GitHub Pages.

This repository is public **only** so GitHub Pages can serve it on the free tier. The
app's own source lives in the private `retail-buddy` repository.

## Two placeholders to fill in before store submission

`index.html` deliberately ships with two placeholders rather than real details, so that
nothing personal ends up in this repository's permanent public history:

| Placeholder | Put here |
|---|---|
| `[DEVELOPER/COMPANY NAME]` | The business name that stands behind the app |
| `[YOUR EMAIL ADDRESS]` | A support address that actually reaches you |

Both are marked with an HTML comment directly above them. Edit the text, commit, push —
GitHub Pages redeploys within a minute or so.

Apple and Google both require a contact that works, so the email must be filled in before
you submit. Consider a dedicated address rather than a personal one: anything published on
a public page gets scraped by spam bots.

## The date

`Last updated:` is plain text near the top. Change it whenever the terms change.
